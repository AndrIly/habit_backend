# Habit Tracker Telegram Bot

Telegram-бот для трекинга привычек с backend на FastAPI, авторизацией через Telegram WebApp и хранением данных в SQLite.

## О проекте

Проект представляет собой систему для отслеживания привычек, где пользователь взаимодействует с Telegram-ботом, а backend отвечает за авторизацию, хранение данных и обработку логики приложения.

Проект демонстрирует:
- работу с Telegram Bot API
- backend-разработку на FastAPI
- авторизацию через Telegram WebApp
- работу с SQLite
- реализацию напоминаний и пользовательских сессий

## Основные возможности

- авторизация через Telegram WebApp
- создание и хранение привычек
- отметка выполнения привычек
- напоминания по времени
- хранение пользователей и сессий
- backend API для обработки авторизации и логики приложения

## Архитектура проекта

Проект состоит из двух основных частей:

1. **Telegram Bot**
   - отвечает за взаимодействие с пользователем
   - показывает меню
   - принимает действия пользователя
   - отображает привычки и их статусы

2. **FastAPI Backend**
   - принимает данные из Telegram WebApp
   - валидирует `initData`
   - создаёт пользовательскую сессию
   - работает с базой данных

## Авторизация через Telegram WebApp

Сценарий авторизации:
1. Пользователь открывает WebApp из Telegram-бота
2. WebApp получает `tg.initData`
3. `initData` отправляется на backend
4. Backend проверяет подпись и актуальность данных
5. После успешной проверки создаётся сессия
6. WebApp отправляет результат обратно в бота
7. Бот сохраняет `session_id` и подтверждает авторизацию

Такой подход позволяет выполнять вход без логина и пароля, используя подтверждённые данные Telegram.

## База данных

В SQLite хранятся:
- пользователи
- сессии авторизации
- привычки
- статусы выполнения
- данные по напоминаниям

## Структура проекта

- `api/` — backend на FastAPI
- `handlers/` — обработчики Telegram-бота
- `keyboards/` — клавиатуры
- `database/` — работа с БД
- `states/` — состояния
- `utils/` — вспомогательные функции
- `scheduler.py` — логика напоминаний
- `main.py` — точка входа для бота
